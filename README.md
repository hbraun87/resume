# henrybraun.info

Source for the portfolio of **Henry Braun** — Engineering Manager at Bad Robot Games, founder of Maned Wolf Games, and game engineer behind award-winning VR/AR titles at Schell Games.

**Status:** planning. The site has not been built yet. This repository currently holds the complete build brief that guides its development:

- [`docs/brief/README.md`](docs/brief/README.md) — start here: goals, architecture, content model, quality bar, and build plan.
- [`CLAUDE.md`](CLAUDE.md) — working rules for the AI agent that builds and maintains the site.

The finished site will be a static [Astro](https://astro.build) site deployed to GitHub Pages at [henrybraun.info](https://henrybraun.info), with all portfolio content in a single JSON file and every deploy gated on Lighthouse, accessibility, and link checks.
